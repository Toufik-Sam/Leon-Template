# Leon-Template
This project is a pixel-perfect HTML/CSS implementation of the GraphBerry Leon – PSD Agency Template. The goal was to transform the original PSD design into a fully responsive, well-structured, and easy-to-modify website.
Features include semantic HTML, organized CSS, responsive layout techniques, and reusable components.
